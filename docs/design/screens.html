Screen layouts

01Build — the existing screen, unchanged

Answers one question: why did p99 move in the run I just watched? Nothing here is being proposed; it is drawn so the two new surfaces can be judged against it.

Existing. Build mode.

02Review — a second mode, not a third screen

The one question Build structurally cannot answer, and it only exists once there is background load: is this system right across the whole load envelope, not just the run I watched?

Proposed. Review mode — same route, same store, same playhead.

Two corrections to the sketch. The terminal as a pop-out modal defeats the Console's only real value — that its output agrees with the canvas in front of you. And the globe loses to the flat map on density: it hides half your PoPs at all times. The sketch already labelled it “alt”; that instinct was right.

03Explorer — right shape, corrected axis

Traffic enters from the left and passes through columns, exactly as sketched. The columns are the latency waterfall rather than OSI layers, because every column is then a quantity measured in every run.

Proposed. Eight columns, generated from the content registries.

Why not L0–L7. Counted against the 41 levels: L2 has zero, L5 and L6 have zero, L7 has thirty-plus — and Kubernetes and security have no OSI layer at all. Seven equal columns advertise seven equal bodies of content that do not exist. Empty columns read as an unfinished game.

Generate it, don't author it. Tag levels, terms and components with a column id and derive the explorer from the existing registries. Two hand-maintained hierarchies over one body of content is how an educational project rots — and this repo already built the antidote for exactly that reason.

The layered model still gets taught — as a primer before Act I, as a second lens toggled over the same tagged content, and as footnotes on the levels that earn it. Because the explorer is generated, a second tag dimension costs nothing. In a reference view a sparse layer is informative; it was only as a campaign map that empty columns read as unfinished.

Layers tell you what a thing is. The waterfall tells you when it happens to your request. One is a taxonomy, the other a timeline — both true, only one of them a route through a curriculum.

04Navigation — one shell, two modes, one overlay

Proposed. No router required yet — two tabs on one route.

Switching modes must not stop playback. Both read the same playhead, and Review must never call simulate itself — a second grading path is how the numbers start disagreeing with each other.
